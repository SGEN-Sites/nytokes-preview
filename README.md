# Toke Cannabis New York: redesign preview

A redesign preview of [nytokes.com](https://www.nytokes.com/) (Toke Cannabis New York, Yonkers and Spring Valley, NY), rebuilt on RISE Cannabis's site architecture: shop by category, brands, deals, rewards, dispensaries, delivery areas, learn hub, FAQ and recipes. It keeps Toke's brand, every word of the live site, its photos and its URLs.

**Preview:** https://sgen-sites.github.io/nytokes-preview/

- This is **not** the live site. Every page is `noindex, nofollow`.
- The shop pages run Toke's own Dutchie menus (Yonkers and Spring Valley). Every category, brand and product button opens that menu already filtered, with the cart.
- Forms are preview-only: nothing typed into them is sent.
- Static HTML, CSS and JS with no framework, served by GitHub Pages from `main` (root).
